# ESP32-C3-WROOM-02 Development Board

## Overview

This project is a custom 2-layer development board designed around the ESP32-C3-WROOM-02 Wi‑Fi + Bluetooth MCU module. The board includes USB Type‑C power input, onboard 3.3V regulation, boot/reset circuitry, GPIO breakout headers, and USB protection components.

## Features

* ESP32-C3-WROOM-02 module
* USB Type‑C interface
* Onboard 3.3V regulator
* Boot and reset buttons
* GPIO breakout headers
* USB ESD protection
* Power indicator LED
* 2-layer PCB design

## Applications

* IoT devices
* Embedded development
* Sensor interfacing
* Wireless communication projects
* Learning and prototyping

## Hardware Included

* ESP32-C3-WROOM-02 MCU module
* USB Type‑C connector
* Voltage regulator
* Decoupling capacitors
* ESD protection devices
* Boot/reset circuitry
* GPIO expansion headers

## Notes

* Operates on 3.3V logic
* Powered through USB Type‑C
* Suitable for firmware development using ESP-IDF or Arduino framework
